# 周边游产品网站

这是根据《周边产品.xlsx》生成的第一版响应式静态网站代码。无需数据库、无需构建工具，适合先快速上线验证。

## 文件结构

```text
周边游产品网站/
├─ index.html            # 网站首页
├─ assets/
│  ├─ styles.css         # 手机 / 电脑响应式样式
│  ├─ data.js            # 24 条线路数据
│  ├─ app.js             # 筛选、搜索、详情、分享、联系方式配置
│  └─ favicon.svg        # 浏览器图标
├─ vercel.json           # Vercel 静态部署配置
└─ README.md
```

## 本地预览

直接双击 `index.html` 即可打开；也可以在项目目录运行一个简单静态服务器：

```bash
python3 -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。

## 修改品牌和联系方式

打开 `assets/app.js` 最上方：

```js
const SITE_CONFIG = {
  brandName: "周边精选",
  phone: "",
  wechat: "",
  consultantName: "旅行顾问"
};
```

把品牌名称、电话、微信号换成真实信息即可。

## 修改线路

线路数据都在 `assets/data.js` 中。每条产品支持：

- `name`：线路名称
- `destination`：目的地
- `days`：天数
- `spots`：主要景点
- `categories`：主题标签
- `itinerary`：每日行程
- `transport`：交通方式
- `suitable`：适合客群
- `note`：内部发布前核对提示（可选）

## 已实现功能

- 手机 / 平板 / 电脑自适应
- 24 条产品卡片
- 关键词搜索
- 按 1 / 2 / 3 日筛选
- 按主题筛选
- 按目的地筛选
- 产品详情侧边页 / 手机全屏详情
- 独立产品分享链接，如 `?product=12`
- 支持 Web Share API，手机可直接调起系统分享
- 联系方式可配置
- 不依赖第三方 JS/CSS 库

## 上线方式

### Vercel / Netlify / Cloudflare

把整个文件夹上传或连接 Git 仓库即可作为静态站点发布，不需要构建命令。

### 中国大陆服务器

可以上传到阿里云 / 腾讯云服务器或对象存储静态网站。若使用中国大陆服务器和自有域名正式公开访问，请按实际主体情况办理备案。

## 发布前建议核对

原始表格中有两条数据建议确认后再正式发布：

1. `溧水两日游` 的景点和行程实际指向溧阳（天目湖、南山竹海）。
2. `宁波、仙居3日游` 第 2 天上午、下午都写了“溪口”，建议细化具体景点。

当前代码保留了原始线路名称，并在详情中加入“发布前核对”提示。
